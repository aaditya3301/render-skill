# Burger showcase

`animation.gif` records the actual page generated by the bundled Render engine.
The recorder drives real window scrolling and captures the engine's card on each
frame. It does not replace the engine with a separate animation or an AI video.

The six registered PNGs select vertical motion, fixed-camera `iso` input, a spread
of 220 canvas pixels, and a scroll-only trigger. `scene.json` records that generated
configuration. The GIF is a recording; a generated HTML page responds to your scroll.

## Reproduce

From the repository root, prepare the original cutouts on common 1800 × 1500
transparent canvases. The source preparation script uses Node.js and Sharp:

```sh
npm ci
node docs/examples/burger/prepare-layers.mjs output/burger-layers
```

Build the scroll animation, preserving artwork credit:

```sh
node skills/render/scripts/render.mjs --input output/burger-layers --output output/burger --product "Burger" --artwork-credit "Artwork by smford; https://github.com/smford/hamburger-decomp; AGPL-3.0"
```

Open `output/burger/index.html` to try it. To record the README GIF, install the
development dependencies and Playwright Chromium, then run:

```sh
node examples/record-scroll.mjs --html output/burger/index.html --output docs/examples/burger/animation.gif
```

The recorder uses Chrome on Windows, Playwright Chromium elsewhere, or `CHROME_PATH`.
It verifies that the page is scroll-driven and ends assembled before saving the GIF.
